# Змейка Хасанатор

Браузерная аркадная игра «Змейка» с темами оформления, скинами и управлением для мобильных устройств.

## Запуск на компьютере

Нужен Python 3. В корне проекта выполните:

```powershell
python server.py
```

Откройте в браузере [http://127.0.0.1:55373](http://127.0.0.1:55373).

## Запуск на телефоне

Подключите телефон и компьютер к одной локальной сети. В корне проекта запустите сервер, доступный в сети:

```powershell
python -m http.server 55373 --bind 0.0.0.0
```

На телефоне откройте `http://<IP-адрес-компьютера>:55373`, заменив пример на локальный IPv4-адрес компьютера. При запросе Windows разрешите доступ к Python для частной сети.

## Структура

- `index.html` — страница игры.
- `game.js` — игровая логика.
- `style.css`, `game-ui.css` — оформление.
- `assets/sounds/` — звуковые файлы.
